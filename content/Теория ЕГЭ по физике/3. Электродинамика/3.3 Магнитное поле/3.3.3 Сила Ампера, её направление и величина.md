# Сила Ампера, её направление и величина

В пункте 3.3.2 мы говорили, что электрический ток создаёт магнитное поле. Теперь рассматриваем обратную сторону связи: **магнитное поле действует на проводник с током**.

**==Сила Ампера==** - сила, с которой магнитное поле действует на проводник с током.

Если участок прямого проводника длиной $l$ находится в однородном магнитном поле с индукцией $\vec B$, то модуль силы Ампера равен

$$
F_A = IBl\sin\alpha,
$$

где:

- $F_A$ - модуль силы Ампера;
- $I$ - сила тока в проводнике;
- $B$ - модуль магнитной индукции;
- $l$ - длина участка проводника, находящегося в магнитном поле;
- $\alpha$ - угол между направлением проводника, то есть направлением тока, и вектором $\vec B$.

Из формулы видно: сила Ампера тем больше, чем больше ток, индукция поля и длина участка проводника в поле.

## Роль угла

Множитель $\sin\alpha$ показывает, что действует только та часть магнитного поля, которая перпендикулярна проводнику.

Частные случаи:

- если проводник перпендикулярен линиям магнитной индукции, то $\alpha = 90^\circ$ и

$$
F_A = IBl;
$$

- если проводник параллелен линиям магнитной индукции, то $\alpha = 0^\circ$ и

$$
F_A = 0.
$$

`Важно!` Если ток направлен вдоль магнитного поля, сила Ампера на прямой участок проводника не действует.

## Направление силы Ампера

Сила Ампера направлена перпендикулярно и к направлению тока, и к направлению магнитного поля. Поэтому её направление нельзя определить только по формуле для модуля.

Для направления используют **правило левой руки**:

1. расположи левую руку так, чтобы линии магнитной индукции входили в ладонь;
2. четыре вытянутых пальца направь по току;
3. отогнутый большой палец покажет направление силы Ампера.

![[3.3.3-sila-ampera.svg|Направление силы Ампера по правилу левой руки|760]]

На схеме магнитное поле направлено от наблюдателя в плоскость рисунка, ток идёт вправо, поэтому сила Ампера направлена вверх.

## Что физически происходит

В металлическом проводнике ток связан с направленным движением свободных электронов. Магнитное поле действует на движущиеся заряды, а через них - на весь проводник. Поэтому проводник может смещаться, если он не закреплён.

В школьной теории для ЕГЭ обычно не выводят силу Ампера из движения электронов подробно. Главное знать:

- магнитное поле действует на проводник только при наличии тока;
- направление силы задаётся правилом левой руки;
- модуль силы вычисляется по формуле $F_A = IBl\sin\alpha$.

## Не путать

1. Опыт Эрстеда: ток создаёт магнитное поле. Сила Ампера: магнитное поле действует на проводник с током.
2. Направление $\vec B$ не совпадает с направлением силы Ампера. Сила перпендикулярна к направлению поля и к направлению тока.
3. В формуле $l$ - длина той части проводника, которая находится в магнитном поле.
4. Если проводник расположен вдоль линий магнитной индукции, сила Ампера равна нулю.
5. Правило левой руки для силы Ампера применяют к направлению тока, а не к направлению движения электронов.

## Коротко

Сила Ампера - сила действия магнитного поля на проводник с током. Её модуль равен $F_A = IBl\sin\alpha$, где $\alpha$ - угол между направлением тока и вектором магнитной индукции. Направление силы находят по правилу левой руки: линии $\vec B$ входят в ладонь, четыре пальца направлены по току, большой палец показывает $\vec F_A$.
