Положение изображения можно вычислить по [[Теория ЕГЭ по физике/3. Электродинамика/3.6 Оптика/3.6.7 Формула тонкой линзы. Увеличение, даваемое линзой|формуле тонкой линзы]], а направление лучей, вид и ориентацию изображения определяют геометрическим построением.

## Побочная оптическая ось и фокальная плоскость

**==Побочная оптическая ось==** — любая прямая, которая проходит через оптический центр $O$, но не совпадает с главной оптической осью.

**==Фокальная плоскость==** проходит через главный фокус перпендикулярно главной оптической оси. Точку пересечения побочной оси с фокальной плоскостью называют **побочным фокусом** $P$.

## Ход произвольно наклонённого луча

Пусть падающий луч не параллелен главной оптической оси и не проходит через оптический центр. Его дальнейший ход строят так:

1. Через $O$ проводят побочную оптическую ось, параллельную падающему лучу.
2. Находят побочный фокус $P$ — точку пересечения этой оси с нужной фокальной плоскостью.
3. Для **собирающей линзы** преломлённый луч проводят через $P$ в фокальной плоскости за линзой.
4. Для **рассеивающей линзы** преломлённый луч проводят так, чтобы его продолжение прошло через $P$ в фокальной плоскости перед линзой.

> [!important] Важно
> Побочная ось — вспомогательная линия, а не световой луч. Она нужна только для нахождения побочного фокуса.

## Лучи, удобные для построения изображений

Для построения обычно выбирают два из трёх характерных лучей, исходящих из одной точки предмета:

1. Луч через оптический центр $O$ не изменяет направления.
2. Луч, параллельный главной оптической оси, после собирающей линзы проходит через дальний фокус, а после рассеивающей идёт так, что его продолжение проходит через ближний фокус.
3. Луч, направленный через ближний фокус собирающей линзы, после линзы идёт параллельно главной оси. Для рассеивающей линзы параллельно оси выходит луч, продолжение которого до линзы направлено к дальнему фокусу.

## Изображение точки и отрезка

Чтобы построить **изображение точки**, из неё проводят два различных луча и строят их ход после линзы:

- точка пересечения самих преломлённых лучей даёт **действительное изображение**;
- точка пересечения продолжений расходящихся лучей даёт **мнимое изображение**.

Если исходная точка лежит на главной оптической оси, один луч проводят вдоль этой оси, а второй выбирают произвольно и строят с помощью побочного фокуса.

Чтобы построить **изображение отрезка**, находят изображения его концов и соединяют их. Для отрезка-стрелки, перпендикулярного главной оси, обычно достаточно построить изображение верхнего конца: изображение нижнего конца лежит на оси.

## Какими получаются изображения

### Собирающая линза

Вид изображения зависит от положения предмета:

- дальше $2F$ — действительное, перевёрнутое, уменьшенное;
- в точке $2F$ — действительное, перевёрнутое, равное предмету по размеру;
- между $F$ и $2F$ — действительное, перевёрнутое, увеличенное;
- в фокальной плоскости — лучи после линзы параллельны, конечного изображения нет;
- между линзой и $F$ — мнимое, прямое, увеличенное.

### Рассеивающая линза

Рассеивающая линза даёт действительному предмету **мнимое, прямое и уменьшенное** изображение. Оно расположено между линзой и её ближним фокусом.

## Система линз

В системе линз построение выполняют **последовательно**:

1. Строят изображение предмета первой линзой.
2. Считают это промежуточное изображение предметом для второй линзы.
3. Строят изображение второй линзой и при необходимости повторяют шаги для следующих линз.

При переходе от одной линзы к другой сохраняют реальные направления лучей и отдельно показывают штриховыми линиями только их продолжения. Итоговый вид изображения определяют по последней ступени построения.

## Не путать

- Действительное изображение образовано лучами и может быть получено на экране; мнимое образовано их продолжениями и на экране не получается.
- Для нахождения изображения достаточно двух удобных лучей, но изображение создаёт весь пучок лучей от точки предмета.
- В системе линз промежуточное изображение не является окончательным: оно служит предметом для следующей линзы.

## Коротко

Произвольно наклонённый луч строят с помощью параллельной ему побочной оптической оси и побочного фокуса. Изображение точки находят пересечением двух преломлённых лучей или их продолжений, изображение отрезка — по изображениям его концов. В системе линз построение выполняют последовательно от первой линзы к последней. Эти правила объясняют образование изображений в [[Теория ЕГЭ по физике/3. Электродинамика/3.6 Оптика/3.6.9 Фотоаппарат как оптический прибор. Глаз как оптическая система|фотоаппарате и глазе]].
