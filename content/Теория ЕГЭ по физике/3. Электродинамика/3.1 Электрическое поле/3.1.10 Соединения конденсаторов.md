---
title: "3.1.10 Соединения конденсаторов"
---

Несколько конденсаторов можно заменить одним эквивалентным конденсатором. Его электроёмкость подбирают так, чтобы при том же напряжении или заряде внешняя цепь "видела" такую же систему.

Основная связь для каждого конденсатора:

$$
q_i = C_i U_i
$$

где $C_i$ - электроёмкость $i$-го конденсатора, $U_i$ - напряжение на нём, $q_i$ - модуль заряда его обкладки.

![[3.1.10-soedineniya-kondensatorov.svg|Параллельное и последовательное соединение конденсаторов|900]]

## Параллельное соединение

При параллельном соединении одни обкладки всех конденсаторов подключены к одной точке цепи, другие - к другой точке. Поэтому напряжение на каждом конденсаторе одинаково:

$$
U_1 = U_2 = \ldots = U
$$

Общий заряд батареи равен сумме зарядов на отдельных конденсаторах:

$$
q = q_1 + q_2 + \ldots
$$

Выведем формулу для эквивалентной ёмкости. Для каждого конденсатора $q_i = C_i U$, значит:

$$
q = C_1U + C_2U + \ldots = (C_1 + C_2 + \ldots)U
$$

С другой стороны, для всей батареи $q = C_{\text{паралл}}U$. Поэтому:

$$
\boxed{C_{\text{паралл}} = C_1 + C_2 + \ldots}
$$

> [!important] Важно
> При параллельном соединении эквивалентная ёмкость больше каждой из отдельных ёмкостей: конденсаторов становится как бы "больше по площади".

## Последовательное соединение

При последовательном соединении конденсаторы соединены цепочкой. Заряды на всех последовательно соединённых конденсаторах одинаковы по модулю:

$$
q_1 = q_2 = \ldots = q
$$

Общее напряжение на батарее равно сумме напряжений на отдельных конденсаторах:

$$
U = U_1 + U_2 + \ldots
$$

Выведем формулу для эквивалентной ёмкости. Из $q = C_iU_i$ получаем:

$$
U_i = \frac{q}{C_i}
$$

Тогда:

$$
U = \frac{q}{C_1} + \frac{q}{C_2} + \ldots = q\left(\frac{1}{C_1} + \frac{1}{C_2} + \ldots\right)
$$

Для всей батареи $U = \dfrac{q}{C_{\text{посл}}}$. Поэтому:

$$
\boxed{\frac{1}{C_{\text{посл}}} = \frac{1}{C_1} + \frac{1}{C_2} + \ldots}
$$

Для двух последовательно соединённых конденсаторов удобно помнить следствие:

$$
C_{\text{посл}} = \frac{C_1C_2}{C_1 + C_2}
$$

> [!important] Важно
> При последовательном соединении эквивалентная ёмкость меньше каждой из отдельных ёмкостей.

## Не путать

Для конденсаторов правила соединения отличаются от правил для резисторов:

- при параллельном соединении складываются сами ёмкости;
- при последовательном соединении складываются обратные ёмкости.

Это связано с тем, что [[Теория ЕГЭ по физике/3. Электродинамика/3.1 Электрическое поле/3.1.9 Конденсатор. Электроёмкость конденсатора|электроёмкость конденсатора]] задаётся отношением заряда к напряжению: $C = \dfrac{q}{U}$.

В этом пункте речь только о соединениях конденсаторов. Энергия заряженного конденсатора относится к следующему пункту кодификатора.

## Коротко

- При параллельном соединении: $q = q_1 + q_2 + \ldots$, $U_1 = U_2 = \ldots$, $C_{\text{паралл}} = C_1 + C_2 + \ldots$.
- При последовательном соединении: $U = U_1 + U_2 + \ldots$, $q_1 = q_2 = \ldots$, $\dfrac{1}{C_{\text{посл}}} = \dfrac{1}{C_1} + \dfrac{1}{C_2} + \ldots$.
- Параллельное соединение увеличивает общую ёмкость.
- Последовательное соединение уменьшает общую ёмкость.
