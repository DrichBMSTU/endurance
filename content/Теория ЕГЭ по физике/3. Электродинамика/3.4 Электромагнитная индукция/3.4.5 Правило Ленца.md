# Правило Ленца

При изменении [[Теория ЕГЭ по физике/3. Электродинамика/3.4 Электромагнитная индукция/3.4.1 Поток вектора магнитной индукции|магнитного потока]] через замкнутый проводящий контур в нём возникает индукционный ток. Направление этого тока определяют по **правилу Ленца**.

**==Правило Ленца==**: индукционный ток направлен так, что создаваемый им магнитный поток препятствует изменению внешнего магнитного потока, вызвавшему этот ток.

**Важно!** Индукционный ток противодействует не внешнему магнитному полю вообще, а **изменению** магнитного потока через контур.

## Как действует правило

Индукционный ток создаёт собственное магнитное поле $\vec B_{\text{инд}}$. Его направление зависит от того, как меняется внешний магнитный поток:

- если внешний поток **увеличивается**, поле индукционного тока направлено так, чтобы ослабить это увеличение;
- если внешний поток **уменьшается**, поле индукционного тока направлено так, чтобы поддержать убывающий поток.

На рисунке внешний поток направлен к наблюдателю. При его увеличении индукционное поле направлено от наблюдателя, а при уменьшении — к наблюдателю. Направление тока найдено по правилу буравчика.

## Алгоритм определения направления тока

1. Определить направление внешнего магнитного поля через контур.
2. Установить, увеличивается или уменьшается внешний магнитный поток.
3. По правилу Ленца определить направление поля $\vec B_{\text{инд}}$:
   - против внешнего поля, если поток увеличивается;
   - по внешнему полю, если поток уменьшается.
4. По [[Теория ЕГЭ по физике/3. Электродинамика/3.3 Магнитное поле/3.3.2 Опыт Эрстеда. Магнитное поле проводника с током|правилу буравчика]] определить направление индукционного тока, создающего поле $\vec B_{\text{инд}}$.

## Физический смысл

Правило Ленца является проявлением закона сохранения энергии. Если бы индукционный ток усиливал вызвавшее его изменение, магнитный поток и ток могли бы самопроизвольно возрастать без затраты энергии.

На практике изменение потока приходится поддерживать внешним воздействием. Например, при приближении магнита к замкнутому контуру возникающий ток создаёт поле, которое препятствует приближению магнита.

## Связь со знаком в законе Фарадея

Знак «минус» в [[Теория ЕГЭ по физике/3. Электродинамика/3.4 Электромагнитная индукция/3.4.3 Закон электромагнитной индукции Фарадея|законе электромагнитной индукции Фарадея]] выражает правило Ленца: направление ЭДС индукции противоположно тому направлению, которое усиливало бы изменение магнитного потока.

## Не путать

1. Если внешний поток уменьшается, поле индукционного тока направлено **так же**, как внешнее поле: оно препятствует уменьшению потока.
2. Направление тока нельзя определять сразу по внешнему полю. Сначала нужно установить характер изменения потока, затем найти $\vec B_{\text{инд}}$.
3. Правило Ленца определяет направление индукционного тока. Величину ЭДС индукции определяет закон Фарадея.
4. Индукционный ток существует только в замкнутом контуре; в разомкнутом контуре может возникать ЭДС индукции, но ток не течёт.

## Коротко

Индукционный ток всегда мешает изменению магнитного потока, которое вызвало этот ток. При увеличении внешнего потока поле индукционного тока направлено против внешнего поля, а при уменьшении — по внешнему полю.
